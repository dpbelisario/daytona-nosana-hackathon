One demo, step by step
  1. Prospect submits email + airline on the Vercel page.
  2. Generator asks Nosana (qwen3:8b) for network, fleet, colour; checks it against IATA data.
  3. Daytona sandbox starts from the snapshot (reused if the airline already has one).
  4. belli-api migrates and seeds: flights, aircraft, ULDs, AWBs with the real prefix.
  5. Airline name, colour and logo go into the frontend; services start.
  6. Prospect opens the dashboard and booking portal.
